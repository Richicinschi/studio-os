# Messaging framework

## The chain

Each layer rests on the one above it.

```
Mission              why the brand exists
   ↓
Vision               where it is heading
   ↓
Value proposition    what it offers
   ↓
Positioning          why it is different
   ↓
Key messages         what it says
   ↓
Proof points         why anyone should believe it
```

## Statement formulas

Mission:
```
We [do what] for [whom] by [how], so they can [reach what].
```

Vision:
```
A world in which [the change we want to see].
```

Value proposition:
```
For [customers] who [have this need],
[Brand] is a [category]
that [delivers this benefit].
Unlike [alternatives],
we [do this differently].
```

Positioning:
```
[Brand] is the [category] for [audience]
who want [result],
because [reason to believe].
```

## The message set

Primary message: a single sentence holding the core value.

Supporting messages (three to five): each covers a separate benefit or audience need.

## Pitches

Common lengths, as a rule of thumb:
- **10 seconds:** one sentence that makes someone ask a question.
- **30 seconds:** the problem, the answer, and what sets it apart.
- **60 seconds:** the whole story, with the proof points.

## Five tests

1. Clear: no jargon in the way.
2. Different: a rival could not say the same.
3. Believable: there is evidence for it.
4. Compelling: the audience cares.
5. Consistent: it fits the rest of the brand.
