# Studio OS kit

You are inside the Studio OS adoption kit, not inside the person's own setup.

- If they want to adopt the kit or an update of it: read `ADOPT.md` and follow it. It starts with `drill-to-adopt`.
- If they want one item: run `vet-and-adopt` on it.
- If they want their folders set up or reorganized for Claude: run `setup-workspace`.
- Never install or copy anything from this repo into their setup outside that protocol, and never write into this repo on their behalf.
- Maintainers working on the kit itself: read `docs/MAINTAINING.md` instead.
