# Visual identity basics

## Elements

### Logo
- **Primary:** the full logo, horizontal or stacked
- **Secondary:** a shortened version
- **Mark:** the symbol by itself
- **Clear space:** the least empty margin around it
- **Minimum size:** the smallest size at which it still reads

### Colour
```
Primary (1-2)
├── the main brand colour
└── a supporting primary

Secondary (2-3)
├── accent colours
└── supporting visuals

Neutrals (3-4)
├── text
├── backgrounds
└── interface parts
```

### Type
Fill in one line per role: font name, weight and size range. A usual starting point:
- H1: bold, 32-48px
- H2: semibold, 24-32px
- Body: regular, 16-18px
- Caption: regular, 12-14px

## Quick checks

### Logo
- [ ] Version suits the setting
- [ ] Enough clear space
- [ ] Legible at the size used
- [ ] Colour version suits the background

### Colour
- [ ] Taken from the approved palette
- [ ] Contrast is accessible
- [ ] The same across materials

### Type
- [ ] Right fonts
- [ ] Sensible hierarchy
- [ ] Readable size
