# Marketing psychology

## When to use

Typical asks: "why do people buy this", "which cognitive bias explains the drop", "how do I use social proof without faking it", "should I show a higher anchor price", "give me persuasion ideas for the launch".

Neighbours, and where each takes over:
- cro: psychology applied to one page, form or pricing page layout.
- pricing: choosing the actual prices and tiers; use the price-perception part here for the buyer side.
- copywriting: writing the words once the framing is picked.
- popups, if a popup skill is installed: timing and triggers of popups; otherwise cro covers them.
- ab-testing: turning a psychological idea into a test.

## How it works

1. Look for a product marketing context file (`.agents/product-marketing.md`, or the older `product-marketing-context.md`). If one exists, read it and tailor everything to that product and audience.
2. Pin down the situation with these questions, asking only the unclear ones: which behaviour do you want, what does the customer believe beforehand, where in the journey (awareness, consideration, decision) is this, what blocks the action now, and has any of it been tried with real customers.
3. Pick the two to four models that fit, using the lookup table below. Open the matching reference file for details:
   - [foundations](marketing-psychology/foundations.md): strategy thinking models.
   - [buyers](marketing-psychology/buyers.md): how customers think and decide.
   - [persuasion](marketing-psychology/persuasion.md): influence principles.
   - [pricing and design](marketing-psychology/pricing-and-design.md): price perception and behaviour design.
   - [growth](marketing-psychology/growth.md): compounding and scaling.
4. For each model give: the idea in one sentence, the marketing use for this product, and a concrete, honest way to apply it.
5. Add an ethics note per model: how it could be abused here, and the honest version. Recommend a test before a full rollout.

Lookup table:

| Problem | Models to start with |
|---|---|
| Low conversion | Hick's law, activation energy, Fogg model, friction |
| Price pushback | Anchoring, framing, mental accounting, loss aversion |
| Trust gap | Authority, social proof, reciprocity, pratfall effect |
| Need for urgency | Scarcity (real only), loss aversion, Zeigarnik effect |
| Churn | Endowment effect, switching costs, status-quo bias |
| Stalled growth | Theory of constraints, local vs global optima, compounding |
| Choice paralysis | Paradox of choice, default effect, nudges |
| Onboarding | Goal-gradient, IKEA effect, commitment and consistency |

Ethical persuasion only. Scarcity, deadlines, reviews and counts must be true. No pre-ticked paid add-ons, hidden renewals, fake countdowns, invented crowds or guilt-based exits. If an idea only works while the buyer does not notice it, drop it.

## Checks before done

- Every model chosen fits the stated behaviour and journey stage, not just sounds clever.
- Each recommendation has a concrete example for this product and an honest version.
- Scarcity, social proof and price references are all real and verifiable.
- Anything posted or spent (ads, discounts) is flagged for the owner to approve with its cost.
- Suggested next step is a small test, with the metric named.
