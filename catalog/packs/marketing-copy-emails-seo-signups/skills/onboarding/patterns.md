# Step orders by product type

Starting sequences to adapt, not to copy. Replace each step with the real action in the product at hand.

| Product type | Typical order | What to watch |
|---|---|---|
| Business software sold self-serve | Short setup wizard, first value action, invite a colleague, deeper configuration | Inviting too early can stall a lone evaluator; offer it after the first result |
| Two-sided marketplace | Complete profile, browse, first transaction, repeat loop | The first transaction is the activation; shorten everything before it |
| Mobile app | Permissions, quick win, notification opt-in, habit loop | Ask for each permission at the moment its benefit is obvious |
| Content platform | Pick interests, consume, create, engage | Make the first feed good before asking for any effort |

## Choosing between orders

- If personalisation changes what the first result looks like, ask the one or two questions that drive it and nothing else.
- If data entry is the barrier, offer sample data or a template so the result appears before the effort.
- If a step is needed only for later features, move it after activation.
- If the value arrives only with other people involved, plan the invite step and a solo fallback.
