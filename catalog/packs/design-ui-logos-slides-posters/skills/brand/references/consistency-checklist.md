# Consistency audit

Go through each block for the material under review.

## Look

### Logo
- [ ] The current version
- [ ] Clear space around it
- [ ] Only approved colours
- [ ] Legible at every size used
- [ ] No edits to the mark

### Colour
- [ ] Palette colours and nothing else
- [ ] Applied the same way each time
- [ ] Enough contrast to read
- [ ] Colour ratios kept

### Type
- [ ] Brand fonts
- [ ] Right weights and styles
- [ ] A visible hierarchy
- [ ] Formatting treated the same everywhere

### Imagery
- [ ] Matches the brand's image style
- [ ] Same editing and filters across pieces
- [ ] Suitable subjects
- [ ] Meets the quality bar

## Sound

### Tone
- [ ] Fits the brand personality
- [ ] Suits the setting
- [ ] Same on every channel
- [ ] No messages that contradict each other

### Language
- [ ] Brand terms used
- [ ] Capitalisation handled the same way
- [ ] Abbreviations correct
- [ ] Jargon at the right level

### Messaging
- [ ] In line with the key messages
- [ ] The value is plain to see
- [ ] Differentiators are visible
- [ ] Calls to action match

## Channels

### Website
- [ ] Home page
- [ ] Product pages
- [ ] Blog and articles
- [ ] Footer and navigation

### Social
- [ ] Profile pictures
- [ ] Cover images
- [ ] Bios and about text
- [ ] Post templates

### Email
- [ ] Header and footer
- [ ] Templates
- [ ] Signatures
- [ ] Automated messages

### Collateral
- [ ] Presentations
- [ ] One-page sheets
- [ ] Business cards
- [ ] Promotional items

## Frequent faults

| Fault | Remedy |
|-------|--------|
| Old logo still in use | Swap in the current one |
| Colours off the palette | Move them onto it |
| Wrong typeface | Use the brand font |
| Voice drifts between pieces | Apply the voice guide |
| Messages disagree | Rewrite from the framework |

## How often

A good default cadence, to adjust to how fast the brand changes:

| What | Cadence |
|------|---------|
| Website | Every month |
| Social profiles | Every quarter |
| Email templates | Every quarter |
| Sales material | Every quarter |
| Whole brand | Once a year |
