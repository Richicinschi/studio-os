# Final QA checklist

Run this before handing edited copy back. Tick each line or note why it does not apply.

## Setup
- [ ] The goal of the text is stated
- [ ] The audience is named
- [ ] The action the reader should take is clear
- [ ] You read the whole text once before changing anything

## Pass 1, clarity
- [ ] A first-time reader gets every sentence
- [ ] Jargon is explained or replaced
- [ ] Each pronoun points at one thing
- [ ] No sentence carries more than one job

## Pass 2, voice and tone
- [ ] Same level of formality throughout
- [ ] The brand personality holds
- [ ] No abrupt mood changes
- [ ] It sounds right read aloud

## Pass 3, so what
- [ ] Each feature leads to a benefit
- [ ] Each claim says why the reader should care
- [ ] The benefits are things the reader wants
- [ ] No line sounds big but means nothing

## Pass 4, prove it
- [ ] Claims have support
- [ ] Social proof is specific and credited to someone
- [ ] Figures name their source
- [ ] No superlative without evidence

## Pass 5, specificity
- [ ] Vague words became concrete ones
- [ ] Numbers and timeframes are there where they apply
- [ ] Generic lines were made specific or cut
- [ ] Filler is gone

## Pass 6, emotion
- [ ] The text makes the reader feel, not only learn
- [ ] The pain is recognisable
- [ ] The goal feels reachable
- [ ] The feeling is honest and serves the message

## Pass 7, zero risk
- [ ] Objections are answered near the call to action
- [ ] Trust signals are present
- [ ] The next step is unmistakable
- [ ] Any guarantee, trial or cancellation promise is stated, and it is one the business really offers

## Last look
- [ ] No typos or grammar slips
- [ ] Formatting is consistent
- [ ] Links open the right place
- [ ] The core message is intact after all edits
