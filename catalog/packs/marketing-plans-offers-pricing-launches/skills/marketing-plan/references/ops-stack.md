# Operations stack: skills and tools per funnel stage

Section 11 shows which studio skills and which tool connections run each part of the plan. The thesis to state: a small team, a planner, a skill library and connected tools can produce what a much larger marketing organisation would. Make that visible in four ways: skills by stage, tools by stage, one concrete proof, and capability by funding tier.

Some names below belong to other skill packs or to tools the client may not have. In this studio library, ads, popups, free-tools, revops, sales-enablement, typefully and marketing-website-design have no skill file of their own (lead-magnets covers free tools, ad-creative covers paid creative). Before you name a skill in the plan, check that it is installed; if it is not, fall back to the underlying tactic, mark it "not installed" and list the gap among the open decisions.

## Skills by stage

- **Acquisition:** seo-audit (site health), ai-seo (visibility in AI answers), programmatic-seo (templated page sets), schema (structured data), content-strategy (topics, pillars, cadence), competitors (comparison and alternative pages), ads and ad-creative (paid campaigns and variants), social and typefully (writing and scheduling founder posts), cold-email (B2B outreach), analytics (tracking, events), free-tools (tools as marketing), marketing-website-design, launch (launch planning and execution).
- **Activation:** onboarding, signup, cro (any page or form), paywalls, popups, copywriting, copy-editing, ab-testing, marketing-psychology, plus any live-copy or full-site-copy skills installed.
- **Retention:** emails (sequences for the chosen email tool), churn-prevention (cancellation flows, save offers, failed-payment recovery), copywriting and copy-editing, ab-testing for subject lines and timing.
- **Referral:** referrals (referral, affiliate and ambassador programs), social (shareable content), copywriting (recruit and onboard messages), marketing-website-design (per-partner landing pages), emails (partner lifecycle: welcome, digest, payout notices).
- **Revenue:** pricing, paywalls, sales-enablement (decks, one-pagers, demos), revops (lead handoff), ab-testing (annual-default, intro-price and tier tests).
- **Cross-cutting:** product-marketing (builds the context file with positioning, ICP and voice; run first), customer-research, marketing-psychology, marketing-ideas (feeds section 12).

## Tool connections by stage

- **Acquisition:** SEO data API, SERP data API, web analytics connector, code host connector (marketing site and content), social scheduler connector, ad-account connector once budget exists, browser automation and clean-page extraction for research, notes tool, payments connector for LTV and CAC reconciliation.
- **Activation:** store console (mostly manual or by browser automation), code host (onboarding code edits), design tool connector, lifecycle email connector, payments connector (subscription state), web analytics (activation events).
- **Retention:** lifecycle email connector (flows, segments, sends), shop platform (physical-purchase triggers), payments (cohorts, plan changes), web analytics (retention curves); other email senders if the stack differs.
- **Referral:** short-link attribution tool, payments (commissions and payouts), code host (partner pages), lifecycle email (partner lifecycle); other affiliate platforms as alternatives.
- **Revenue:** payments (price tests, subscription analytics, churn cohorts, blended CAC), shop platform, web analytics (revenue events), lifecycle email, notes tool.
- **Cross-cutting:** shared notes tool, shared context repository, research extraction, personal notes, design files.

Before adding any connector that costs money or sends data to a new service, ask and state the cost. Prefer what the client already pays for.

## Capability by funding tier

| Tier | People | Tools | Channels |
|---|---|---|---|
| Pre-seed or bootstrapped | planner plus founders | current tools plus skills and connections | organic only |
| Seed closed | plus first marketing hire | plus ad accounts, ads skill active | plus paid pilot |
| Seed deployed | plus designer (maybe fractional) | plus deeper analytics | plus paid scale and first launches |
| Series A | plus performance lead and content lead | plus a larger software and event budget | aggressive paid, international thinking, B2B verticals |
| Series B and later | marketing org of 10 or more | plus agencies and PR firm | brand campaigns, acquisitions, category sponsorships |

funding-tiers.md gives a method for sizing spend, not dollar bands; any figure in a plan is the person's own ceiling or range, or an invented example labelled as such.

## The proof requirement

Section 11 must include at least one concrete event showing the stack works. It must be a specific happening, from this client's history if possible, performed by a non-technical person without engineering help. Shapes that work: "On the first call, a founder drafted a working abandoned-cart flow live through the email connector." "Within two weeks the site went from no ranking keywords to roughly thirty using templated pages plus the SEO data connector." If the client has no such story, present the week-one demonstration the team will run to prove it.

## When nothing is connected

Do not claim the thesis. List the skills that work with current tools, say which connection would unlock which section, and treat connector set-up as quarter-1 work beside the foundation fixes.
