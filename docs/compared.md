# What Claude Code does on its own, and what the kit adds

Claude Code already does a good part of what this kit is about. Before you adopt an item, it is worth knowing which part is Claude Code's and which part the kit adds, so you take only what you lack. This page compares the kit with Claude Code itself, not with other kits. Each statement about Claude Code links the section of [docs/facts.md](facts.md) it rests on, with its date there.

| The problem | What Claude Code does on its own | What the kit adds |
|---|---|---|
| A new day starts from zero | Reads `CLAUDE.md` at every start (`AGENTS.md` when there is no `CLAUDE.md`, or through an import), and keeps auto memory, a folder per project whose `MEMORY.md` loads at the start ("Claude Code: where skills, agents and instruction files load from"). `/resume` reopens a conversation ("Claude Code: context commands, subagents, extra folders"), but its first request the next day reprocesses the whole history ("Prompt cache and why a new day starts cold"). | A front door written for your work, a handoff note written at the end of each session and read at the start of the next, a memory index whose rules you set, and a fresh session that proves it: [module 01](../modules/01-continuity/README.md). |
| Long chats get slow, and the model is a guess | `/context` shows what fills the window, `/compact` summarizes it ("Claude Code: measuring context and asking multiple choice"), and a default model is set for you, with effort levels you can change ("Models: which for what"). | Habits that keep a session light (a fresh session per task, bulk reading in a subagent), a table of which model for which kind of task, and every item's cost to every session before you take it: [module 02](../modules/02-context-and-models/README.md), [the feature menu](../catalog/FEATURES.md). |
| A skill or plugin from outside might not be safe | Shows what a plugin adds and asks you to review it before you install it; a plugin runs code as you ("Claude Code: installed plugins and their skills"). An automatic scan of what a skill or plugin holds is not described. | A pinned scanner, SkillSpector, run before anything from outside is installed, every finding read and recorded, and the installed copy scanned again: [cards/skillspector.md](../cards/skillspector.md), [module 05](../modules/05-skills/README.md). |
| Claude runs git with nothing to stop a mistake | A shell command that is not read-only waits for your yes, unless you allowed it; permission rules and hooks can refuse a command; and the sandbox, off by default, can fence shell commands on macOS, Linux and WSL2 ("Claude Code: permission rules for secret files", "Claude Code: hooks", "Claude Code: the sandbox"). You write the rules. | A git guard with a tested list of the commands it refuses and the ones it lets through, commit hooks that stop secrets and conflict markers, merge commits only ([module 06](../modules/06-git-and-guardrails/README.md)), and signed commits ([cards/signed-commits.md](../cards/signed-commits.md)). |
| A secret file read into a session | Deny rules for `Read`, enforced by Claude Code ("Claude Code: permission rules for secret files"). | A tested set of rules for secret files, with the gaps the tests found, and an audit that never opens them: [cards/sensitive-file-deny-rules.md](../cards/sensitive-file-deny-rules.md). |
| Work called done before it is | Plan mode, subagents, and bundled skills where your plan and platform offer them: `/code-review`, and `/verify`, which runs your app to confirm a change does what it should ("Claude Code: context commands, subagents, extra folders", "Claude Code: bundled commands"). | A plan before code, success criteria first, review by a separate agent, and a check before anything is called done: [module 03](../modules/03-planning/README.md), [module 04](../modules/04-delegation/README.md). |
| A change you want to take back | `/rewind` takes the conversation and the code back to an earlier point ("Claude Code: context commands, subagents, extra folders"). | An Undo on every card, and each adopted item recorded with how to undo it in your `adoption/decisions.md`. |

## When Claude Code alone is enough

- **If one of the problems above never bites you,** its row's kit column is not for you. The drill asks before it offers anything, and "skip" is a good answer.
- **If you work alone, in one repository, and start each day with `/resume`,** its built-in memory may already carry you. Try the kit's short path first, "Start with continuity" ([START-HERE.md](../START-HERE.md)), and take more only if the fresh-session check shows a gap.
