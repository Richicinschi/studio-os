# Decision framework

Work from the outside in: the situation, then the kind of motion, then the details, then a final check.

## 1. Read the situation

Audience:
- A stressed user wants calm motion; a browsing user can take more.
- Someone mid-task wants quick and minimal; an explorer tolerates drama.
- Something seen a hundred times a day should be fast and discreet; something seen once may be dramatic.

Surroundings:
- A crowded layout calls for simpler motion; an empty one allows more.
- If other animations are running, coordinate or stagger with them.
- A small container means small movement.

## 2. Name the purpose

| Purpose | Do this | Protect |
|---|---|---|
| Reward | overshoot, particles | delight |
| Confirm an action | immediate reply | speed |
| Catch the eye | scale, colour, pulse | responsiveness |
| Lead through steps | stagger, directional flow | clarity |
| Show how things relate | position, links | legibility |
| Set a mood | subtle and continuous | restraint |

## 3. Choose the kind of motion

Category: reveal (content appears), conceal (content goes), transition (between states or views), emphasise, respond to input, or ambient atmosphere.

Personality: match the brand; see [motion-personality.md](motion-personality.md).

Direction carries meaning:

| Direction | Reads as |
|---|---|
| Up | growth, aspiration |
| Down | settling, finishing |
| Right | moving forward, arriving |
| Left | going back, leaving |
| Scaling up | importance, emerging |
| Scaling down | dismissal, removal |
| Toward the center | focus, converging |
| Away from the center | spreading, release |

## 4. Fill in the details

Properties: the fewest that work, two being ideal; see [property-selection.md](../reference/property-selection.md). Timing: take the duration table value and adjust for distance and weight. Easing: arriving ease-out, leaving ease-in, visible ease-in-out, looping sine.

Shortcuts by purpose:
- Feedback: short, ease-out, minimal.
- Entrance: ease-out in the chosen personality.
- Exit: ease-in, about 70% of the entrance time.
- Emphasis: a scale or colour pulse.
- Ambient: slow, continuous, sine.

Shortcuts by cue word: fun or bouncy means Playful; elegant or luxury means Premium; clean or business means Corporate; bold or dynamic means Energetic.

## 5. Final check

| Test | Ask |
|---|---|
| Purpose | does it do a clear job? |
| Personality | does it fit the brand and setting? |
| Repetition | is it still pleasant the hundredth time? |
| Attention | does it leave the viewer's focus alone? |
| Hierarchy | does it show what matters most? |
| Layers | primary present, secondary and ambient added? |
| Timing | right length for what it is? |
