# Platform limits for ad copy

Numbers below are carried over from the earlier version of this skill and were not re-measured; the balanced-set splits are the skill's own starting points. Platforms change them, so confirm each one in the platform's own ad preview before launch.

## Google Ads

Responsive search ads:

| Slot | Limit | Count |
|---|---|---|
| Headline | 30 characters | 3 required, up to 15 |
| Description | 90 characters | 2 required, up to 4 |
| Display path | 15 characters each | 2, optional |
| Final URL | none stated | required |

The system shows up to 3 headlines and 2 descriptions in any order unless you pin. Pinning limits its testing, so pin sparingly: the brand name in slot 1 only if brand rules demand it, the strongest call to action in slot 2 or 3, and the rest free.

A balanced set of 15 headlines: 3 or 4 that echo search intent, 3 or 4 on benefits, 2 or 3 on proof, 2 or 3 calls to action, 1 or 2 on what sets you apart, and 1 with the brand name.

A balanced set of 4 descriptions: benefit plus proof; feature plus outcome; proof plus call to action; offer or deadline plus call to action when one exists.

Performance Max and display:

| Slot | Limit | Count per asset group (Performance Max) |
|---|---|---|
| Headline | 30 characters | 3 to 15 |
| Long headline | 90 characters | 1 to 5 |
| Description | 90 characters | 2 to 5 |
| Business name | 25 characters | 1 (required only when brand guidelines are off) |

The Performance Max counts come from Google's Ads API asset requirements page. Some guides also mention a 60 character short description; it is not in that table, so check Google's current help page before relying on it.

## Meta (Facebook and Instagram)

| Slot | Recommended | Hard maximum |
|---|---|---|
| Primary text | 125 | 2,200 |
| Headline | 40 | 255 |
| Description | 30 | 255 (often not shown) |
| Display link | 40 | n/a |

Placements: in feed everything shows. In stories and reels the text sits over the media, so keep it near 72 characters. In the right column only the headline is visible. Audience network varies by publisher.

Habits that help: hook in the first 125 characters, line breaks in long text, no more than 1 or 2 emojis, a question now and then, a headline that states the value or the action.

Lead form: greeting headline 60, greeting description 360, privacy text 200. These lead form figures and the hard maximums above could not be confirmed on a Meta page, and some sources say Meta publishes only recommended lengths. Check Ads Manager.

## LinkedIn

| Format | Slot | Recommended | Maximum |
|---|---|---|---|
| Single image | Intro text | 150 | 600 in older guides, 3,000 on LinkedIn's current help page; check |
| Single image | Headline | 70 | 200 |
| Single image | Description | 100 | 300 (some placements only) |
| Carousel | Intro text | n/a | 255 |
| Carousel | Card headline | n/a | 45 |
| Carousel | Cards | n/a | 2 to 10 |
| Message ad | Subject | n/a | 60 |
| Message ad | Body | n/a | 1,500 |
| Message ad | Button | n/a | 20 |
| Text ad | Headline | n/a | 25 |
| Text ad | Description | n/a | 75 |

Tone: professional but alive, the vocabulary of the reader's job, figures and data, no consumer-style hype, peer voices over brand voices.

## TikTok

| Slot | Recommended | Maximum |
|---|---|---|
| Ad text | 80 | 100 |
| Display name | n/a | about 20 (most guides say 2 to 20 Latin characters; the earlier figure here was 40, so check) |
| Button | pick from the platform list | fixed set |

Boosted organic posts reuse the original caption and the creator handle; only the button is added. Tone: native beats polished, the opening seconds matter most, text on screen matters because many watch muted, vertical 9:16 only.

## X

| Slot | Limit |
|---|---|
| Post text | 280 |
| Website card headline | 70 |
| Website card description | 200 |

Tone: conversational, short sentences, one message per post, 0 to 2 hashtags (none is often better in ads).

The LinkedIn message ad and text ad figures come from third-party guides, not LinkedIn's own page; confirm them in Campaign Manager. A conversation ad button has a different limit from the message ad button.

## Counting rules

- Spaces, symbols such as the pipe and ampersand, and links inside body text all count.
- An emoji counts as 1 or 2 depending on the platform.
- Dynamic keyword insertion (`{KeyWord:default}` in Google Ads) can push a line over its limit, so choose a short safe default.

## Writing for several platforms at once

Start with the tightest slot and widen. Write the 30 character search headline first, which forces a clear core message. Widen to the 40 character Meta headline by adding a word or two. Widen again to the 150 character LinkedIn intro with context and proof, and finally to the Meta primary text with the full hook and value statement.
