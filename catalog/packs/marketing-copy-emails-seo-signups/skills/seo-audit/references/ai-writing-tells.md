# Writing tells to strip from audit reports and page copy

Readers and detectors spot text that reads as machine-made. When you write fixes, rewrites of titles, or the report itself, clean these out.

## Dashes

Long dashes are the most reliable tell. Studio rule: use none at all, long or short. Swap in a comma, a colon, parentheses or a new sentence. Number ranges use the word "to" (50 to 60 characters).

## Words to swap

| Avoid | Say |
|---|---|
| delve, explore in depth | look at |
| leverage, utilise | use |
| facilitate | help |
| foster, bolster | support, strengthen |
| streamline, optimise | simplify, improve |
| robust, comprehensive | solid, full |
| pivotal, crucial, vital | key, important |
| seamless | smooth |
| cutting-edge, groundbreaking, innovative | new |
| holistic, multifaceted, intricate, nuanced | whole, varied, complex |
| furthermore, moreover | also, and |
| a myriad of, a plethora of | many |
| prior to, subsequent to | before, after |
| in terms of, with respect to | for, about |
| shed light on, pave the way for | explain, allow |
| underscore, unveil, endeavour | stress, show, try |
| ascertain, elucidate | find out, explain |
| transformative | major |
| notwithstanding | despite |
| paramount | very important |
| pertaining to | about |
| in light of | because of |
| the fact that | that, or reword |
| in the realm of, in an era of | in |

## Openers, bridges and closers

Cut: "In today's fast-paced world", "In the ever-evolving landscape of", "It's worth noting that", "Let's dive in", "Imagine a world where", "That being said", "At its core", "In conclusion", "At the end of the day", "All things considered", "To sum up", "With that in mind", "In essence", "This begs the question", "In today's digital age", "To put it simply".

Cut these shapes too: the "whether you are a X, a Y or a Z" list, the "not only X but also Y" pivot, a long metaphor that opens with "think of", and sentences that begin "By doing X, you can Y".

## Empty intensifiers

Delete unless they carry real meaning: very, really, quite, extremely, incredibly, truly, absolutely, definitely, certainly, surely, undoubtedly, obviously, clearly, naturally, simply, basically, essentially, fundamentally, ultimately, actually, significantly, interestingly.

## Self-check

1. Read it aloud; rewrite anything you would not say to a colleague.
2. Look for repeated sentence shapes and clusters of the words above.
3. Mix short and long sentences.
4. Keep an intensifier only if removing it changes the meaning.
