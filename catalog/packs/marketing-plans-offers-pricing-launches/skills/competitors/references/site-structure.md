# Index pages and footer links

## Alternatives index

Purpose: one page listing every "X alternative" page.
Outline: a headline naming your product as an alternative; a short intro on why people move to you; a list where each entry has the rival name, a one-line difference, and the link; the switch reasons that recur across rivals; a call to action.
Entry style: "Alternative to Kettlebase: better when you bill in several currencies."

## Comparisons index

Purpose: one page listing every you-vs and rival-vs-rival page.
Outline: headline; a section of direct comparisons with you; a section of head-to-head pages between rivals; a short note on how you compare (sources, dates); call to action.

## Keeping indexes useful

- Add each new page to its index on the day it ships.
- Link index to page and page back to index; cross-link related pages.
- Index pages can rank for broad terms such as "invoicing tool comparisons" and pass authority to the pages below them.
- Sort by search demand, alphabet, use case, or recency. Show a last-updated date and a count of pages; add filters when the list is long.

## Footer links

The footer sits on every marketing page, so it distributes links to the whole comparison set.

Minimum: a Compare group with one link to each index.

Stronger: one footer column per format you have actually built (vs, alternatives, head-to-head), each with a handful of links (up to 8 is a starting point) to the rivals with the most search demand and a "view all" link to the index. Do not create a column for a format with no pages.

Notes:
- Add new high-priority pages to the footer when they ship, but do not list every page.
- Name columns after the URL folders.
- On phones columns stack, so put the highest priority first.
