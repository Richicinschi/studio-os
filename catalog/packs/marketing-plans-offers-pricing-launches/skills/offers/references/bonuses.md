# Bonuses that help instead of pad

## Three jobs

1. Lift the felt value of the whole package.
2. Soften risk: if the core disappoints, the buyer still got something.
3. Answer one specific objection each. This is the job people skip.

## Match bonus to objection

| Buyer thinks | Bonus that answers it |
|---|---|
| "I will not have time" | Setup done for them in week one |
| "Which tools do I pick?" | A short vetted tool list |
| "What if I get stuck?" | Thirty days of written support |
| "My boss will not agree" | A ready-made internal pitch |
| "I tried this before" | A story from someone with the same history |
| "My niche is odd" | A reference note for that niche |
| "I will drown in new software" | Templates for the tools you already suggest |
| "I never finish things" | A check-in at day 30 |
| "My case is complicated" | A one-to-one call to tailor the plan |

Finding the real objections: read refund emails and sales call notes from recent months; read your page aloud and note each doubt; ask three recent buyers what nearly stopped them. Expect three to six clusters, then build one bonus per cluster.

## Rules for stated value

1. Quote a value only if you can point to a comparable price.
2. Keep the bonus total under about twice the core price (a starting point, not a measured value; tune it).
3. Include only things you would genuinely sell on their own.
4. Name each bonus by its outcome, not "toolkit".

## A 3 to 5 bonus shape

| Slot | Type | Answers |
|---|---|---|
| 1 | Speed | "This will take too long" |
| 2 | Trust | "Will it work for me?" |
| 3 | Stuck | "What if I hit a wall?" |
| 4 | Decision | "I cannot choose between options" |
| 5 (optional) | Reach | Adds a neighbouring outcome |

Illustration for a small-business accounting course: (1) a pack of invoice and expense templates; (2) walkthroughs of real, consented setups from earlier students (a proof item, so no price is claimed); (3) six weeks of fortnightly office hours; (4) a short comparison of three invoicing tools; (5) a session on setting rates. Add up only the items you could sell alone and check the sum against the twice-the-price rule.

## When bonuses backfire

- Inflated: a giant "value" next to a modest price triggers distrust.
- Patching the core: a bonus that fixes a gap in the core tells buyers the core is unfinished.
- Replacing the core: buyers purchase for the extras, receive a thin core, then ask for refunds. Build the core first.
- Too many: beyond five it looks like a funnel, and premium buyers skip the list.
- Same as everyone: a "private community" that every rival offers is table stakes. Choose extras tied to your buyer's actual situation.

## Delivery timing

Day one: speed items. Weeks two to four: support items. At the finish: identity items such as a certificate or alumni access. Releasing everything at once removes the reason to continue; holding some for completion raises finishing and referrals.

## Audit each bonus

1. Which objection does it close? If none, cut it.
2. Can you defend its value with a comparable? If not, drop the figure.
3. Is it delivered at a point that helps the customer, not just the checkout?
4. Could any competitor offer the same? Then replace it.
5. Would the bonus sell without the core? If yes, the core is weak; repair the core.

Typical fix: cut to three to five specific bonuses, name them clearly, put honest values on them.
