# Incentives and sizing

## Reward types

| Type | Upside | Downside | Fits |
|---|---|---|---|
| Cash or account credit | Everyone values it | Feels like a transaction | Marketplaces, money apps |
| Product credit | Pulls people into using the product | Only useful if they will use it | Subscriptions, SaaS |
| Free months | Easy to understand | Can attract freebie hunters | Subscription products |
| Feature unlock | Almost free to give | Needs gated features | Freemium |
| Physical gifts | Memorable, people show them off | Shipping and stock work | Brand-led companies |
| Charity donation | Feels good | Weaker personal pull | Mission-driven brands |

Ask the user before choosing: each type has a real cost (cash out, margin given up, or shipping). Quote that cost per reward.

## Design patterns worth copying

- Reward tied to the product itself (extra storage for a storage product) so the gift is also a reason to use it.
- Matching reward for both sides, triggered when the friend takes a first real action.
- Milestone ladders with small physical items: each step is cheap next to the value of a subscriber, and the items get shown to others.
- Aim at a group that already shares a lot (students, teams) and give credit, which keeps people active.
- One-field invitation: an email address or a link, nothing more.

## Ceiling for the reward

    max reward = (customer LTV x gross margin) - target CAC

Example with made-up numbers: LTV 900, gross margin 60 percent, target CAC 150. Ceiling = 900 x 0.60 - 150 = 390. Stay well below the ceiling; start low and test upward. Any figure for "typical rewards" is unverified unless the user supplies a source.

## Viral coefficient

    K = invitations per user x conversion rate of invitations

K above 1 means each user brings more than one new user (self-sustaining). K below 1 means referrals add to other acquisition. Example: 4 invitations at 8 percent conversion gives K = 0.32.

Referral rate = customers who refer / all customers. Also track referrals per referrer. Compare against your own earlier months; outside benchmark bands have no source here.

## ROI

    ROI = (revenue from referred customers - program cost) / program cost
    program cost = rewards paid + tool fees + time spent running it

Track separately: CAC via referral, LTV of referred customers, and payback time on rewards.
