# Twelve page-family playbooks

Each family is a repeatable search pattern. For every one: the pattern, what a page must contain to deserve a place in the index, and a URL shape.

| Family | Sample query | Pattern behind it |
|---|---|---|
| Templates | cv template free | "[type] template" |
| Curation | best project trackers | "best [category]" |
| Conversions | 5 miles in km | "[X] to [Y]" |
| Comparisons | linear vs jira | "[X] vs [Y]", "[X] alternative" |
| Examples | pricing page examples | "[type] examples" |
| Locations | plumbers in leeds | "[service] in [place]" |
| Personas | invoicing for photographers | "[product] for [audience]" |
| Integrations | stripe notion integration | "[A] [B] integration" |
| Glossary | what is churn | "what is [term]" |
| Translations | comment faire un devis | same page, other language |
| Directory | accounting software for startups | "[category] tools" |
| Profiles | uber early investors | "[entity]" or "[entity] + attribute" |

## Templates
Downloadable or interactive files people use at once. Needs: files that really work (not previews), several variants per type, quality close to paid options, a short download or use flow. URL: `/templates/[type]/`.

## Curation
Ranked or recommended lists. Needs: stated criteria, real testing or expertise, a visible update date, rankings not driven only by affiliate payout. URL: `/best/[category]/`.

## Conversions
Calculators and converters for units, currencies, formats. Needs: accurate and fresh data, a fast tool that works on a phone, links to related conversions. URL: `/convert/[from]-to-[to]/`.

## Comparisons
Head-to-head pages. Needs: a balanced view, real feature data, a verdict per use case, edits when either product changes. URL: `/compare/[x]-vs-[y]/`. For deeper frameworks use the competitors skill.

## Examples
Galleries of real work. Needs: genuine, good examples with screenshots or embeds, filters, and a short analysis of why each works. URL: `/examples/[type]/`.

## Locations
One page per service and place. Needs: real local data (providers, prices, rules), not a city name dropped into identical text; a map helps. URL: `/[service]/[city]/`.

## Personas
Pages tailored to a role or industry. Needs: copy and features chosen for that segment, use cases from it, proof from customers in it. URL: `/for/[persona]/`.

## Integrations
How your product works with another. Needs: real setup steps, concrete use cases for the pair, and an integration that actually ships. URL: `/integrations/[product]/`.

## Glossary
Definitions of field terms. Needs: a precise definition, examples, links to related terms, more depth than a dictionary entry. URL: `/glossary/[term]/`.

## Translations
Your pages in other languages. Needs: human-quality translation with local adaptation, correct hreflang tags, review by a native speaker. URL: `/[lang]/[page]/`. Studio note: the studio ships English only unless a law or platform forces otherwise, so use this family only for a market you have decided to serve.

## Directory
Broad listings of a category. Needs: wide coverage, filtering and sorting, real detail on each listing, regular refreshes. URL: `/directory/[category]/`.

## Profiles
Pages about people, companies or entities. Needs: sourced and current facts, an original angle or aggregation, more than a rewrite of an encyclopedia entry. URL: `/companies/[name]/` or `/people/[name]/`.

## Matching a family to what you own

| You own | Lean toward |
|---|---|
| Proprietary data or statistics | Directory, Profiles |
| Integrations | Integrations |
| A design or creative product | Templates, Examples |
| Several audience segments | Personas |
| A local presence | Locations |
| A tool or utility | Conversions |
| Expertise and content | Glossary, Curation |
| Reach beyond one language | Translations |
| Named competitors | Comparisons |

## Layering
Families combine when each layer adds a real fact:
- Locations with Personas: design studios for nonprofits in Denver
- Curation with Locations: best climbing gyms in Portland
- Integrations with Personas: Teams for support agents
- Glossary with Translations: definitions in several languages
